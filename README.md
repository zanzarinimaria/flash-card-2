# flash-card-2
Site de perguntas e respostas (flashcard) desenvolvido para estudos, aplicando conceitos de HTML, CSSe manipulação do DOM com JavaScript

## como usar
1. Crie 3 arquivos na mesma pasta (`index.html`, `style.css`, `script.js).
2. Dê dois cliques no arquivo `index.html` para abrir direto no seu navegador.
